# اختبارات لوحة الإدارة

تفتح لوحة الإدارة الحقيقية (`admin.html` + `admin.js`) في متصفح Chromium، وتستبدل GitHub بخادم وهمي، فلا تلمس موقعك ولا مستودعاتك ولا تحتاج رمزاً حقيقياً.

## التشغيل
```
npm i -D playwright        # مرة واحدة
node tests/run-all.mjs     # كل الاختبارات
node tests/entry-and-merge.test.mjs   # اختبار واحد
```
إن كان Playwright مثبّتاً في مكان آخر: `PLAYWRIGHT_MODULE=/المسار/playwright/index.mjs node tests/run-all.mjs`

## ماذا يغطي كل ملف
| الملف | يتحقق من |
|---|---|
| `publish` | نشر عقار جديد كاملاً: الصفحات، الخريطة، بطاقات المشاركة، بقاء الحقول السرية خاصة |
| `photo-protection` | الصور في المستودع الخاص فقط، والمعرض مشفّر، وفتحه بالمفتاح الصحيح فقط |
| `gallery-preview` | معاينة الرابط الخاص قبل النشر |
| `entry-and-merge` | الأرقام العربية، تنبيه الأسعار الشاذة، دمج تعديلات جهاز آخر، إعادة المحاولة عند تحرك الفرع |
| `areas` | المناطق الديناميكية: إنشاء منطقة من النموذج، رابط ومحافظة لكل منطقة، أخطاء الرابط، حذف صفحة المنطقة عند انتهاء عقاراتها، وبقاء نصوص التعريف كما هي |
| `category` | التصنيف «استثماري»: النموذج، الفلتر، الصفحات، صفحة الصنف، الوسم، ورسم المجسّم في المتصفح |
| `price-privacy` | السعر «عند التواصل» لا يتسرّب في أي ملف علني أو اسم ملف أو وصف صفحة منطقة، ويظهر عند إعادة تأكيده |
| `verification` | قائمة التحقق لكل عقار: الشارات، التتبع الاختياري للقديم، تواريخ التحقق، انتهاء التفويض، التنبيه قبل النشر، وعدم تسرّبها علناً |
| `sell` | صفحة «لديك عقار للبيع؟» (قناة المالكين): التوليد، السيو، الروابط، النموذج ورسالة واتساب المنظمة، والتحقق من الحقول الناقصة |
| `ai-readiness` | llms.txt و llms-full.txt (من المتاح فقط، السعر المخفي والحقول الخاصة لا تظهر)، ومعرّف موحد للمستشار في البيانات المنظمة، وrobots.txt |
| `verify` | التحقق بعد النشر من أن الموقع تحدّث فعلاً (نجاح، ولا تحديث، وفشل بناء، وشبكة معطلة) وزر «فحص الاتصال» |
| `lifecycle` | حالة «مباع» (تاريخ، إخفاء من الموقع والمعرض)، عمر آخر تحديث و«ما زال متاحاً»، كشف تكرار العقارات |
| `drafts-safety-versions` | المسودة مع 12 صورة، فاحص الجودة قبل النشر، استرجاع النسخ السابقة |
| `drafts-no-indexeddb` | التصفح الخاص: الرجوع للحفظ القديم والتحذير الصريح |
| `site-scroll` | الموقع نفسه: ظهور العناصر عند التمرير، العدّادات، الفلاتر، عارض العقار |
| `perf.mjs` | قياس أداء بمعالج بطيء (ليس اختباراً): `node tests/perf.mjs 4 index.html` |

## قبل أي تعديل على `admin.js` أو `assets/mk.js`
شغّل `node tests/run-all.mjs`. كل ملف هنا كان يكشف خللاً حقيقياً أثناء التطوير.
