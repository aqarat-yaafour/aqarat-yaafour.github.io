ربط اللوحة بموقعك

هالصفحة بتكتب مباشرة على مستودعاتك بـGitHub. بدها مفتاح وصول بتنشئه إنت مرة وحدة. المفتاح بينحفظ بمتصفحك بس — ما بينرسل لأي جهة تانية.

  1. افتح صفحة إنشاء المفتاح (Fine-grained token)
  2. Token name: أي اسم، مثلاً admin
  3. Expiration: اختار No expiration حتى ما يوقف بعد فترة
  4. Repository access ← Only select repositories ← اختار المستودعين
  5. Permissions ← Repository permissions ← Contents ← Read and write
  6. اضغط Generate token، وانسخ المفتاح والصقه تحت
أنشئه من هون باسم mk-inventory واختار Private وأشّر على Add a README file.
